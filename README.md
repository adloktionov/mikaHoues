# House Planner

Браузерный планировщик дома или квартиры: помещения и стены, проёмы, раскладка кладки и ведомость материалов, мебель, варианты расстановки и 3D.

## Быстрый запуск

Нужен **Node.js 24**. Из корня репозитория:

```bash
cd planner
npm ci
npm run dev
```

Открыть [http://127.0.0.1:5174/](http://127.0.0.1:5174/).

## Управление и возможности

[Инструкция пользователя](docs/USER_GUIDE.md) описывает планировку, расстановку, импорт FBX/GLB/glTF, освещение HDRI, сохранение проектов и экспорт PNG.

Проекты сохраняются локально в браузере. Для резервного копирования и переноса используйте экспорт архива. Первый выпуск считает кладочные материалы без цен; фундамент, крыша, OBJ и USD пока не входят в него.

## Проверки и сборка

Из `planner/`:

```bash
npm test
npm run build
npx playwright test --config playwright.production.config.ts
```

Последняя команда запускает один итоговый сценарий на собранном приложении; требуется установленный Google Chrome. Сборка включает проверку TypeScript. Для локального просмотра сборки: `npm run preview` → [http://127.0.0.1:4174/](http://127.0.0.1:4174/).

## Структура

- `planner/` — новое приложение: Vue 3, TypeScript, Pinia, Konva и Three.js; IndexedDB через Dexie.
- `docs/` — инструкция, статус реализации и результаты проверок.
- `ARCHITECTURE.md`, `DECISIONS.md`, `IMPLEMENTATION_PLAN.md` — архитектура, решения и план.
- `project/`, `references/` — исходный ApartmentPlanner и его материалы.

Подготовка публикации в `house.vue` и проверенные ограничения: [отчёт](docs/PUBLICATION.md), [Release QA](docs/RELEASE_QA.md).

# ApartmentPlanner — исходное приложение

Интерактивный 3D-планировщик квартиры: план, прогулка, каталог мебели и независимые варианты расстановки.

## Запуск

Нужен Node.js 20.19 или новее. Из корня репозитория:

```bash
cd project
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/. На macOS также можно запустить `project/Запустить.command` двойным щелчком.

## Проверки и сборка

Из папки `project`:

```bash
npm test
npm run validate
npm run verify:architecture
npm run build
```

## Структура

- `project/` — приложение на JavaScript, Three.js и Vite, данные, тесты и отчёты.
- `references/` — исходные фотографии и план квартиры.
- `furniture-references/` — папка для исходных фотографий пользовательской мебели.

Текущая зафиксированная геометрия — Architecture v3. Исторические версии находятся в `project/versions/`.

Пользовательские варианты сохраняются в браузере. Для переноса и резервных копий используйте экспорт/импорт JSON.

Подробнее об управлении и данных: [инструкция проекта](project/README.md).
