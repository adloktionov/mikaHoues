## Исходная квартира и варианты

Верхний список **«Вариант квартиры»** переключает независимые сцены. **«Исходная квартира»** защищена: это девять восстановленных предметов, исходные материалы и параметры с подтверждённым исправлением коридора. Нажмите **«Создать вариант на основе исходной»** для редактируемой копии или **«Сохранить как новый вариант»** для копии своей расстановки.

**«Показать исходную квартиру»** переключает просмотр и сохраняет вашу расстановку. **«Вернуться к текущему варианту»** возвращает её. После завершённого изменения мебели работает автосохранение; статус сверху подтверждает запись.

**«Управление вариантами»** содержит экспорт всех вариантов, сброс выбранного и удаление. Сброс, удаление и замена при импорте требуют подтверждения. Кнопки **«Экспорт JSON» / «Импорт JSON»** справа работают с выбранным вариантом; по умолчанию импорт создаёт новую копию. Для внешней резервной копии скопируйте JSON в текстовый файл с расширением .json.

Варианты хранятся в этом браузере для этого адреса. Очистка данных сайта удалит пользовательские варианты — сохраняйте внешний JSON. Исходная квартира входит в файлы приложения. Старая расстановка переносится в «Текущий вариант», прежние ключи сохранения остаются без изменений.

Архитектура хранится в data/apartment-data.json и versions/architecture-v3, исходная сцена — data/original-scene.json. Пользовательские варианты ссылаются на архитектуру и хранят свои позиции, размеры, видимость и параметры отдельно.

# Планировщик квартиры

Локальная расчётная модель квартиры по плану и фотографиям. Откройте `http://127.0.0.1:5173/` после запуска. Для полного интерфейса используйте окно браузера шириной от 1100 px.

## Запуск

На этом Mac можно дважды открыть `Запустить.command` в папке проекта. Пока работает планировщик, окно терминала должно оставаться открытым. Остановка — Ctrl+C. Если сервер уже запущен, достаточно открыть адрес выше.

Обычный запуск из папки `project` (Node.js 20.19+):

```sh
npm ci
npm run dev
```

Зависимости и production-сборка уже включены в переданный проект. При запуске на этом Mac повторная установка не требуется. После первой установки приложение не требует Интернета. Исходные фотографии используются только локально.

Для production-проверки:

```sh
npm run build
npm run preview
```

Адрес preview по умолчанию `http://127.0.0.1:4173/`. Это другой адрес хранения браузера: перенесите расстановку через JSON. Открытие index.html двойным щелчком не поддерживается — нужен локальный сервер.

## Управление

- **3D:** левая кнопка вращает камеру, правая сдвигает, колесо меняет масштаб.
- **План:** строго сверху. **Расстановка:** тот же вид с инструментом перемещения.
- **Прогулка:** WASD/стрелки, обзор перетаскиванием мыши. Движение ограничено стенами. Кнопки комнат переводят камеру в нужное помещение.
- **Потолок:** отдельный переключатель. В плане автоматически выключается; при сравнении с фото включается.
- **Измерить ↔:** две точки. В плане измеряется проекция на пол; в 3D — расстояние между выбранными поверхностями. Показаны метры и сантиметры. Третий щелчок начинает новое измерение, Escape выходит.

## Мебель

Нажмите предмет в сцене или списке. Перемещайте его инструментом ✥ либо вводите X/Y/Z в метрах справа. Габариты вводятся в сантиметрах. Y — высота нижней точки над полом. Поворот задаётся числом, кнопками или клавишей R. Сетка и привязка к стенам настраиваются в инспекторе. Предупреждение о пересечении не запрещает экспериментировать с размещением.

Копия: Ctrl/Cmd+D или кнопка. Удаление: Delete или кнопка. Скрытые предметы остаются в списке. Отмена: Ctrl/Cmd+Z, повтор: Ctrl/Cmd+Shift+Z. История хранит до 50 изменений в текущей сессии. Стены в режиме расстановки не двигаются.

Чтобы добавить свою вещь:

1. Храните фотографии в `../furniture-references/название/`.
2. Откройте «Мебель → Создать свой предмет», введите наружные ширину, глубину и высоту.
3. Выберите подходящий тип модели. Каталог и экземпляр сохраняются в браузере.
4. При наличии GLB положите его в `public/models/` и укажите `models/имя.glb` в «Модель и примечание → Применить модель». Рекомендуется латинское имя файла. Y должен смотреть вверх, X соответствовать ширине, Z — глубине.

GLB заменяет внешний вид, сохраняя размеры, положение и угол предмета. Масштабирование по осям вписывает модель в точный габаритный объём. `example-cube.glb` — оранжевый тестовый куб, не предмет квартиры. Если модель не загружается, остаётся габаритный объект. Фотографии мебели автоматически в 3D не превращаются.

## Сохранение

Изменения автоматически сохраняются в этом браузере для текущего адреса; кнопка «Сохранить» делает то же явно. «Экспорт JSON» содержит каталог и экземпляры: габариты, положение, поворот, помещение и видимость. Можно скачать файл или скопировать текст. «Импорт JSON» принимает файл либо вставленный текст; некорректный JSON не заменяет расстановку. Встроенный браузер может ограничивать скачивание — в таком случае используйте текстовый вариант.

«Исходная расстановка» восстанавливает мебель по фотографиям и оставляет пользовательский каталог. Очистка данных браузера удаляет локальное сохранение, поэтому храните JSON отдельно. Модели GLB и изображения в JSON не встраиваются: их нужно переносить вместе с проектом.

## Точность и уточнение размеров

«Комнаты» показывает площади модели и плана с ошибкой. «Проверка» содержит исходный план с обводкой, все 16 фотографий и оценочные камеры. Высота потолка, высота дверей/окон, подоконник и общий множитель толщины стен меняются через «Параметры». Эти параметры сохраняются отдельно в браузере и не экспортируются в layout JSON.

Полная метрическая геометрия: `data/apartment-data.json`. Координаты X/Z — на плане, Y — вверх; 1 единица = 1 метр. Изменение толщины стен пересчитывает полигоны и площади по внутренним граням стен. Ширины отдельных проёмов и координаты стен уточняются в JSON; глобальные высоты берутся из apartment.parameters. Для воспроизводимой реконструкции используйте `data/reconstruction-source.json`, `scripts/fit-plan.py` и `scripts/generate-data.py`. Генератор перезаписывает apartment-data.json и исходный furniture.json: сохраните ручные изменения перед запуском.

Расчёт согласован с семью площадями, но реальные длины ещё требуют обмера. Кухонное окно/эркер и актуальная перегородка отдельного WC неоднозначны. Текущий Geometry QA, статусы и три приоритетных измерения: `geometry-qa-report.md`. Сопоставление всех фотографий: `reconstruction-notes.md`.
